# nanoCoder

nanoCoder is a coding assistant that reads, writes and edits files and runs shell
commands in a workspace. Its application code is provided; you do not need to
modify it for Lab1A.

Follow [Running nanoCoder on nanoFS](../docs/lab1/nanocoder-demo.md) to run a
scripted task on your filesystem. This demo uses Python 3 from the lab container
and needs no model service, API key or additional Python packages.
